# sites/

Community-contributed site documents for the w2agent directory.

Each file is a completed `SITE_TEMPLATE.md` (renamed `<slug>.md`) for a specific site,
generated by following the [AGENTIZE.md](../AGENTIZE.md) SOP.

To contribute a site, see the **"Agentize a Site (Community)"** section in [CONTRIBUTING.md](../CONTRIBUTING.md).
